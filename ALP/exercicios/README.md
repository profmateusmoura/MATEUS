# Exercícios de fixação

Esta pasta contém atividades simples para praticar decisões em Python.

## Como resolver

1. Leia a descrição da atividade.
2. Pense na condição correta.
3. Escreva o `if`, `elif` ou `else`.
4. Teste com alguns valores.

## Dicas

- Sempre verifique a condição antes de escrever o código.
- Use `if` para verificar uma situação.
- Use `elif` quando há mais de uma condição.
- Use `else` para o caso que não entrou nas condições anteriores.
