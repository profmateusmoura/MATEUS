# Exercícios com while

Esta pasta está organizada do mais simples ao mais complexo.

## Ordem de estudo

1. Comece contando e fazendo contagem regressiva.
2. Depois, repita operações usando condições e `if`.
3. Em seguida, acumule valores.
4. Por fim, use entradas do usuário para controlar quando o laço termina.

## Como resolver

1. Leia a descrição.
2. Defina a condição que mantém o laço repetindo.
3. Atualize o contador ou a variável usada na condição.
4. Teste seu código e confira se o laço termina.

## Dicas

- `while` repete enquanto uma condição for verdadeira.
- Inicialize as variáveis antes do laço.
- Atualize dentro do laço as variáveis que controlam sua condição.
- Uma condição que nunca fica falsa pode criar um laço infinito.
