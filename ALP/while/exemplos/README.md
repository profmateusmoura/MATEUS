# Exemplos de while

Esta pasta mostra exemplos simples de uso do laço `while`.

## Conceito principal

O `while` repete um bloco de código enquanto uma condição for verdadeira. A condição é verificada antes de cada repetição.

Exemplo:

```python
contador = 1

while contador <= 3:
    print("Repetição:", contador)
    contador = contador + 1
```

### Explicação

- `contador` começa com o valor 1
- o bloco se repete enquanto `contador <= 3`
- o contador aumenta em cada repetição para que o laço termine

Confira se a condição pode se tornar falsa para evitar um laço infinito. Use esses arquivos como referência antes de fazer os exercícios.
