# Exercícios com for

Esta pasta está organizada do mais simples ao mais complexo.

## Ordem de estudo

1. Primeiro, repita letras e números simples.
2. Depois, use `range()` para contar, somar e tabular.
3. Em seguida, aplique `if` dentro do `for`.
4. Por fim, use listas e cálculos maiores.

## Como resolver

1. Leia a descrição.
2. Identifique a sequência que vai ser repetida.
3. Use `for` com `range()` ou com uma lista.
4. Teste seu código.

## Dicas

- `for` repete um bloco de código.
- `range(1, 10)` vai de 1 até 9.
- `range(10)` vai de 0 até 9.
- Use uma variável para guardar o valor atual da repetição.
