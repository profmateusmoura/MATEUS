# Exemplos de for

Esta pasta mostra exemplos simples de uso do laço `for`.

## Conceito principal

O `for` repete um bloco de código para cada item de uma sequência.

Exemplo:

```python
for i in range(1, 4):
    print("Repetição:", i)
```

### Explicação

- `i` recebe cada valor da sequência
- o código dentro do `for` roda 3 vezes
