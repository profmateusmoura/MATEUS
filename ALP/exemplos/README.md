# Exemplos de decisões em Python

Esta pasta reúne exemplos simples para entender como funcionam as estruturas condicionais.

## Estruturas que você vai ver

- `if`: executa algo quando a condição for verdadeira.
- `else`: executa quando a condição for falsa.
- `elif`: adiciona mais condições entre `if` e `else`.
- `match case`: usado para comparar valores de forma organizada.

## Ideia principal

A estrutura condicional avalia uma condição e decide qual bloco de código será executado.

Exemplo:

```python
idade = 18

if idade >= 18:
    print("Maior de idade")
else:
    print("Menor de idade")
```

### Explicação

- Se `idade >= 18` for verdadeiro, a mensagem “Maior de idade” aparece.
- Se for falso, aparece “Menor de idade”.
